# Memories

Durable topic notes for future threads. Each Markdown file starts with routing
frontmatter; the runtime puts only its path and description in the prompt and
loads the full file on demand.

```markdown
---
description: Deployment procedures and rollback checks. Read before deployments.
---

# Deployments
```

Use lowercase kebab-case filenames, keep one topic per file, and update or delete
stale facts. Do not store transcripts, scratch work, credentials, or personal
secrets.
